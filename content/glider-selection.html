How the data behind this is organised

The cards, table and charts all read one row per glider, extending the columns already in gliders_cleaned.csv. Four companion files join on the same id: payloads.csv (PAM and sensors), integrations.csv (which payload runs on which glider, with evidence), rodeo.csv (straight from build_summary.py) and links.csv (so the reference sites appear in the same place on every card).
