ReadMe for Data Folder

This folder is for ORIGINAL raw or raw-derived data. GitHub is not the place for large files, so
**no data files are committed here** (everything except this ReadMe is gitignored).

Where the data live:

- **Glider Rodeo deployment data** (CSV exports per glider): Glider Rodeo JupyterHub,
  `shared-public/GliderRodeo/<deployment>/`.
- **Soundscape metrics:** Glider Rodeo JupyterHub, `shared-public/GliderRodeo/Noise/`.
- **Raw audio** (about 4.5 TB) is not on the hub; ask the Glider Rodeo organisers.
